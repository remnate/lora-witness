# Release announcement

LoRA Witness v0.1 compares a Kohya SDXL Base LoRA and its native Diffusers export on CPU. It checks 560 loader-tested attention projection identities and reports each file's coverage. The synthetic demo loads successfully after one mid-block query update is halved. An exhaustive comparison identifies that projection and its largest changed coefficient. Install from the checkout and run the two commands in the README. All weights stay local.

## Pilot

Recruit three converter authors, three trainer integrators and four publishers who retain source and export files through opt-in trainer discussions. Ask each participant to run the manifest and example first, then compare one private pair. Ask for consent before collecting a redacted report. File hashes and module names may identify a private project. Request only coverage totals, verdict, the affected supported path if applicable, and whether the participant needs this check again.

Count each person who checks their own pair once. Record unsupported or zero coverage separately from demonstrated discrepancies. After ten pilots, continue toward 100 distinct users through consenting model cards and converter release checklists only if participants found an in-scope discrepancy or recurring verification need. Otherwise offer the synthetic fixture upstream and defer a standalone launch.

Historical reports involving lost convolution or time-embedding keys and MOSS-Image attachment are outside the allowlist. OneTrainer fork export support has also reduced conversion demand. Header validators and merge optimizers already exist. These observations motivated a trial with converter owners. They supply no measured demand or evidence about private adapters.
